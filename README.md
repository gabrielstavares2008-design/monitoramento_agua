# Sistema de Monitoramento de Nível de Água

Simulação em Python de um sistema de controle de níveis de água para reservatórios utilizando a biblioteca `colorama` para exibir alertas coloridos no terminal.

## Funcionalidades

- Exibição de 5 níveis de alerta do reservatório (Muito baixo a Muito alto).
- Cores personalizadas no terminal para facilitar a identificação visual de risco.
- Reset automático da formatação do terminal após a execução.

## Requisitos

- Python 3.x
- Biblioteca `colorama`
